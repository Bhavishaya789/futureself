# Statistics

@study
For grouped data, mean = sum(f x) / sum f using class marks x. Median = l + ((n/2 - cf)/f) x h. Mode = l + ((f1 - f0)/(2 f1 - f0 - f2)) x h. Empirical relation: 3 median = mode + 2 mean. Cumulative frequency curves (ogives) give the median graphically.
## Deep dive: mean of grouped data
Direct method: x = class mark, mean = sum (f x)/sum f. Assumed mean method: d = x - a, mean = a + sum (f d)/sum f. Step-deviation: u = (x - a)/h, mean = a + h x sum (f u)/sum f. All three give the same answer.
## Deep dive: mode and median
Modal class is the class with the highest frequency. Mode = l + ((f1 - f0)/(2 f1 - f0 - f2)) x h, where l is the lower limit of the modal class, f1 its frequency, f0 and f2 the frequencies of the classes before and after, and h the class size. Median class is the class whose cumulative frequency first exceeds n/2. Median = l + ((n/2 - cf)/f) x h where cf is the cumulative frequency of the class before it. Relationship: Mode = 3 Median - 2 Mean.
## Deep dive: ogives
A less-than ogive plots upper class limits against cumulative frequency (less than type); a more-than ogive plots lower limits against cumulative frequency (more than type). The x-coordinate of the intersection of the two ogives is the median; so is the x-value for n/2 on either curve.
**Common mistakes:** using class limits instead of class marks, forgetting to make classes continuous, and taking cf of the median class rather than the class before it.
