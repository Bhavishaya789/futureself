# Python Basics and Control Flow
minutes: 35
yt: class 10 ai and it python basics and control flow
@study
Python is a high-level interpreted language. Variables store values; data types are int, float, str, bool, list, tuple, dict. Operators: arithmetic (+ - * / // % **), comparison, logical (and, or, not). Control flow uses if-elif-else, for and while loops with break and continue. range(start, stop, step) generates numbers up to stop-1. Indentation defines blocks. input() reads text and print() displays output.
## Deep dive: variables and types
Variables are created by assignment and need no declaration. Types: int, float, str, bool. Use int(), float(), str() for conversion; input() always returns a string.
## Deep dive: operators
Arithmetic: + - * / // % **. Comparison: == != < > <= >=. Logical: and, or, not. Precedence: ** then * / // % then + -.
## Deep dive: control flow
if-elif-else picks one branch. for loops iterate over range() or sequences; while loops repeat while a condition holds. break exits; continue skips.
## Deep dive: errors
Syntax errors stop the program from running; runtime errors crash it; logical errors give wrong answers. Debug with print statements and tests.
