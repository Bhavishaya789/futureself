# Web Applications and Security
minutes: 35
yt: class 10 ai and it web applications and security
@study
A web application runs in a browser and communicates with a server over HTTP/HTTPS. The front end uses HTML (structure), CSS (style) and JavaScript (behaviour); the back end handles logic and databases. Web basics include URL, domain name, IP address, DNS, web server and hosting. Security covers HTTPS/SSL, encryption, authentication and authorisation, strong passwords, two-factor authentication, firewalls, antivirus, backups and safe habits against phishing, SQL injection, malware and ransomware. Indian laws include the IT Act 2000.
## Deep dive: how the web works
The browser sends an HTTP request using a URL; DNS finds the IP address of the web server; the server returns HTML, CSS and JavaScript which the browser renders.
## Deep dive: building blocks
HTML gives structure (h1, p, a, img, table), CSS gives style (colour, font, layout), JavaScript gives behaviour. The back end uses databases and server logic.
## Deep dive: security threats
Phishing, malware, ransomware, spyware, SQL injection and weak passwords are common threats. Defences: HTTPS, strong passwords, 2FA, firewalls, antivirus, updates and backups.
## Deep dive: law and ethics
The IT Act 2000 penalises hacking, identity theft and cyber fraud. Respect privacy, avoid plagiarism and report cybercrime at cybercrime.gov.in.

A: A unique number identifying a device on a network.

A: Converts domain names to IP addresses.

A: A computer that stores and serves web pages.

A: Renting space on a server for a website.

A: Software used to view web pages.

A: HyperText Transfer Protocol.

A: The secure version of HTTP using encryption.

A: The connection is encrypted.

A: Converting data into a coded form.

A: Verifying who a user is.

A: Deciding what a user is allowed to do.
Q: What is a strong password?
A: Long, with letters, numbers and symbols.
Q: What is two-factor authentication?
A: Using two proofs of identity.
Q: What is phishing?
A: Fake messages that trick users into revealing information.
Q: What is malware?
A: Software designed to harm a system.
Q: What is ransomware?
A: Malware that locks files until money is paid.
Q: What is a firewall?
A: A system that filters network traffic.
Q: What is SQL injection?
A: An attack inserting malicious SQL into input fields.
Q: What is a cookie?
A: A small file a website stores in the browser.
Q: What is a CAPTCHA?
A: A test to tell humans from bots.

A: India's main law on cybercrime and e-commerce.

A: A virtual private network providing a secure connection.

A: A copy of data for recovery.
Q: What is responsive design?
A: Web design that adapts to screen size.

A: Using internet servers to store and process data.
