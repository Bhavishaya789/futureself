# Electronic Spreadsheet (Advanced)
minutes: 35
yt: class 10 ai and it electronic spreadsheet (advanced)
@study
An electronic spreadsheet (Excel/Calc) organises data in cells identified by column letter and row number. Formulas begin with =. Common functions are SUM, AVERAGE, MAX, MIN, COUNT, IF, VLOOKUP and ROUND. Cell references are relative (A1), absolute ($A$1) and mixed. Features include sorting, filtering, conditional formatting, charts, pivot tables, data validation and named ranges. Errors like #DIV/0!, #NAME?, #VALUE! and #REF! indicate problems.
## Deep dive: formulas and functions
Formulas start with =. Functions: SUM, AVERAGE, MAX, MIN, COUNT, IF, ROUND, VLOOKUP. Relative references shift when copied; absolute ($A$1) do not.
## Deep dive: data tools
Sort and filter data; apply conditional formatting; validate input; build charts and pivot tables to summarise large data.
## Deep dive: errors
#DIV/0! (divide by zero), #NAME? (unknown name), #VALUE! (wrong type), #REF! (invalid reference), ##### (narrow column).
## Deep dive: good practice
Use a header row, named ranges, freeze panes and protect formulas. Check results before presenting.
