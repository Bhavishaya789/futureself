# सन्धिः
minutes: 35
yt: class 10 sanskrit sandhi
@study
सन्धिः नाम वर्णयोः मेलनम्। सन्धिः त्रिविधः अस्ति: स्वरसन्धिः, व्यञ्जनसन्धिः, विसर्गसन्धिः। स्वरसन्धौ दीर्घः (अ/आ+अ/आ=आ), गुणः (अ/आ+इ/ई=ए, उ/ऊ=ओ, ऋ=अर्), वृद्धिः (अ/आ+ए/ऐ=ऐ, ओ/औ=औ), यण् (इ/ई+असमान स्वर = य्, उ/ऊ=व्, ऋ=र्), अयादिः (ए=अय्, ऐ=आय्, ओ=अव्, औ=आव्), पूर्वरूपम्, पररूपम्। व्यञ्जनसन्धौ श्चुत्वम्, ष्टुत्वम्, जश्त्वम्, अनुस्वारः, परसवर्णः, म् का अनुस्वारः। विसर्गसन्धौ उत्वम्, रुत्वम्, सत्वम्, शत्वम्, ओत्वम्, लोपः।
## Deep dive: स्वरसन्धिः
दीर्घसन्धिः: विद्या + आलयः = विद्यालयः। गुणसन्धिः: महा + ईशः = महेशः, सूर्य + उदयः = सूर्योदयः, देव + ऋषिः = देवर्षिः। वृद्धिसन्धिः: एक + एकम् = एकैकम्, सदा + एव = सदैव, महा + ओघः = महौघः। यण्सन्धिः: इति + आदि = इत्यादि, सु + आगतम् = स्वागतम्, पितृ + आज्ञा = पित्राज्ञा। अयादिसन्धिः: ने + अनम् = नयनम्, नौ + इकः = नाविकः, पो + अनः = पवनः, पौ + अकः = पावकः।
## Deep dive: व्यञ्जनसन्धिः
जश्त्वसन्धिः: वाक् + ईशः = वागीशः, दिक् + गजः = दिग्गजः, षट् + आननः = षडाननः। अनुस्वारः: म् + व्यञ्जनम् = अनुस्वारः, यथा – सम् + सारः = संसारः। श्चुत्वम्: सत् + चरित्रम् = सच्चरित्रम्। ष्टुत्वम्: तत् + टीका = तट्टीका। परसवर्णः: जगत् + नाथः = जगन्नाथः। तुगागमः: छ से पूर्व: वृक्ष + छाया = वृक्षच्छाया।
## Deep dive: विसर्गसन्धिः
उत्वम्: शिवः + वन्दे = शिवो वन्दे (अः + अ = ओ ऽ)। रुत्वम्: पुनः + अपि = पुनरपि। सत्वम्: नमः + ते = नमस्ते। शत्वम्: निः + चलः = निश्चलः। ओत्वम्: मनः + हरः = मनोहरः। विसर्गलोपः: देवः + एति = देव एति। रेफ: निः + रोगः = नीरोगः (र् का लोप और दीर्घ)।
## Deep dive: अभ्यासविधिः
सन्धि विच्छेद करते समय पहले दोनों शब्दों के अन्त और आदि वर्ण देखें, फिर नियम की पहचान करें। संयोग में बने वर्ण से पहले वर्ण का मूल रूप पहचानें।
## Hindi saransh
दो वर्णों के मेल को संधि कहते हैं। स्वर संधि में दीर्घ, गुण, वृद्धि, यण्, अयादि आदि आते हैं। विसर्ग संधि में नमः+ते=नमस्ते, पुनः+अपि=पुनरपि जैसे उदाहरण याद रखें।
> सूत्र: अकः सवर्णे दीर्घः, आद्गुणः, वृद्धिरेचि, इको यणचि, एचोऽयवायावः।
