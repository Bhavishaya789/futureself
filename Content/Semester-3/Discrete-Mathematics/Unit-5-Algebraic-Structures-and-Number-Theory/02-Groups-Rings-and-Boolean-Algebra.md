An **algebraic structure** is a set with operations obeying certain laws.

## Groups
A **group (G, ∗)** satisfies:
1. **Closure:** a ∗ b ∈ G.
2. **Associativity.**
3. **Identity** e: a ∗ e = e ∗ a = a.
4. **Inverse** a⁻¹ for every a.
An **abelian** group is also commutative. Examples: (ℤ, +), (ℚ − {0}, ×), (Z_n, +_n), non-zero residues mod a prime under multiplication, symmetric group S_n (permutations; order n!, non-abelian for n ≥ 3).
Weaker structures: **semigroup** (closure + associativity), **monoid** (+ identity). (ℕ, +) is a monoid but not a group; strings with concatenation form a monoid.

## Subgroups, cosets, Lagrange
A subgroup H ≤ G is a subset that is itself a group. **Lagrange's theorem:** |H| divides |G|. So a group of order 7 (prime) has only trivial subgroups and is cyclic.
The **order of an element** a is the smallest n with aⁿ = e. A **cyclic group** is generated by one element, such as Z_6 = ⟨1⟩.
Z_6 under + has subgroups of orders 1, 2, 3, 6.

## Homomorphism and isomorphism
f(a ∗ b) = f(a) ∘ f(b). Isomorphic groups have identical structure. Example: (ℝ, +) ≅ (ℝ⁺, ×) via the exponential function.

## Rings and fields
- **Ring:** abelian group under + and a monoid (semigroup) under ×, with distributive laws. (ℤ, +, ×), matrices.
- **Field:** a commutative ring where every non-zero element has a multiplicative inverse: ℚ, ℝ, ℂ and Z_p for prime p. Z_6 is not a field (2 has no inverse).
- **Finite fields** (Galois fields) are used in error-correcting codes and AES.

## Coding theory (brief)
Hamming distance and parity checks detect and correct errors; a code with minimum distance d detects d − 1 errors and corrects ⌊(d − 1)/2⌋.

## Boolean algebra
A Boolean algebra has ∧, ∨ and complement obeying the laws of sets and logic: identity, complement, commutative, distributive, De Morgan, absorption. Variables take 0/1.
- Boolean functions are written as sums of **minterms** (SOP) or products of **maxterms** (POS).
- **Karnaugh maps** simplify functions by grouping adjacent 1s in powers of two.
Example: F = x'y + xy' + xy simplifies to x + y (since xy' + xy = x, and x'y + x = x + y).
- n variables give 2^(2^n) distinct Boolean functions (16 for n = 2).
Gates: AND, OR, NOT, NAND, NOR (NAND and NOR are universal), XOR.

> Group = closure, associativity, identity, inverse. Field = a ring where division by non-zero is possible.
@qa
Q: List the group axioms.
A: Closure, associativity, an identity element, and an inverse for every element.
Q: What does Lagrange's theorem state?
A: The order of a subgroup divides the order of the finite group.
Q: Is (ℕ, +) a group?
A: No. It has an identity 0 but elements other than 0 have no additive inverse in ℕ, so it is a monoid.
Q: Why is Z_6 not a field while Z_7 is?
A: In Z_6, elements such as 2 and 3 have no multiplicative inverse (they share factors with 6). 7 is prime, so every non-zero element of Z_7 has an inverse.
Q: Simplify xy' + xy.
A: x(y' + y) = x · 1 = x.

## Moderate
P: List the group axioms and check whether (Z5, +) with elements {0, 1, 2, 3, 4} under addition mod 5 is a group.
A: Axioms: closure, associativity, identity and inverses. Closure: the sum mod 5 is in the set. Associativity holds. Identity: 0. Inverses: 0 to 0, 1 to 4, 2 to 3, 3 to 2, 4 to 1. So it is a group (also abelian).

## High
P: Show that {1, 3, 5, 7} under multiplication modulo 8 is a group. What is its order and does every element satisfy x * x = 1?
A: 3 x 5 = 15 = 7, 3 x 7 = 21 = 5, 5 x 7 = 35 = 3 (mod 8), so the set is closed. Identity is 1. Each element is its own inverse: 3 x 3 = 9 = 1, 5 x 5 = 25 = 1, 7 x 7 = 49 = 1. Order is 4. Yes, every element squares to 1 (the Klein four-group).

## Advanced
P: Simplify F = A.B + A.B' + A'.B, naming the laws used. Then give the dual of A + 0 = A.
A: A.B + A.B' = A.(B + B') = A. So F = A + A'.B = A + B (absorption law A + A'.B = A + B). The dual of A + 0 = A is A.1 = A.
