# संधि
minutes: 30
yt: class 9 hindi संधि
@study
दो वर्णों के मेल से जो विकार उत्पन्न होता है उसे संधि कहते हैं। संधि के तीन भेद हैं: स्वर संधि, व्यंजन संधि और विसर्ग संधि। स्वर संधि के पाँच भेद हैं: दीर्घ, गुण, वृद्धि, यण और अयादि।
## गहराई से समझें: स्वर संधि
दीर्घ: अ/आ + अ/आ = आ (विद्या + आलय = विद्यालय); इ/ई + इ/ई = ई; उ/ऊ + उ/ऊ = ऊ। गुण: अ/आ + इ/ई = ए (नर + इंद्र = नरेंद्र), + उ/ऊ = ओ (सूर्य + उदय = सूर्योदय)। वृद्धि: अ/आ + ए/ऐ = ऐ, + ओ/औ = औ (सदा + एव = सदैव)। यण: इ + अ = य (इति + आदि = इत्यादि)। अयादि: ए + अ = अय् (ने + अन = नयन)।
## गहराई से समझें: व्यंजन और विसर्ग संधि
व्यंजन संधि में त् + ज = ज्ज (सत् + जन = सज्जन), त् + न = न्न (उत् + नति = उन्नति)। विसर्ग संधि में विसर्ग का ओ, र्, श्, स् आदि में बदलना होता है: मनः + हर = मनोहर, निः + चल = निश्चल, दुः + जन = दुर्जन।
## Hindi saransh
संधि = मेल। तीन भेद: स्वर, व्यंजन, विसर्ग।
> संधि-विच्छेद का अर्थ है जोड़े हुए शब्द को अलग करना।

Q: 'गुण संधि' का क्या अर्थ है?
