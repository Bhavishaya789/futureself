@study
**Number systems:** natural, whole, integers, rational (p/q), irrational (non-terminating non-repeating, like sqrt 2 and pi), real. Every rational number has a terminating or repeating decimal.
**Polynomials:** an expression like a x^n + ... + c. Degree is the highest power. **Remainder theorem:** the remainder when p(x) is divided by (x - a) is p(a). **Factor theorem:** (x - a) is a factor of p(x) if p(a) = 0.
Identities: (a + b)^2 = a^2 + 2ab + b^2; (a - b)^2 = a^2 - 2ab + b^2; a^2 - b^2 = (a + b)(a - b); (a + b)^3 = a^3 + b^3 + 3ab(a + b).
Example: factorise x^2 - 5x + 6 = (x - 2)(x - 3), because 2 + 3 = 5 and 2 x 3 = 6.
## Deep dive: number systems
**Natural numbers** N = 1, 2, 3, ... **Whole numbers** W = 0, 1, 2, ... **Integers** Z = ..., -2, -1, 0, 1, 2, ... **Rational numbers** Q are numbers p/q with p, q integers and q not 0. **Irrational numbers** cannot be written as p/q; their decimals neither end nor repeat (sqrt 2, sqrt 3, pi). **Real numbers** R = rational + irrational; every real number is a point on the number line and every point is a real number.
**Decimals.** A rational number has a terminating decimal (1/8 = 0.125) or a non-terminating repeating decimal (1/3 = 0.333..., 1/7 = 0.142857 repeating). A fraction in lowest terms terminates only when the denominator has no prime factors other than 2 and 5. To convert 0.666... to p/q put x = 0.666..., 10x = 6.666..., subtract: 9x = 6, so x = 2/3.
**Operations.** The sum or product of a non-zero rational and an irrational is irrational. The sum or product of two irrationals may be rational (sqrt 2 x sqrt 2 = 2) or irrational. Rationalising the denominator: 1/(a + sqrt b) = (a - sqrt b)/(a^2 - b).
**Laws of exponents.** a^m x a^n = a^(m+n); a^m / a^n = a^(m-n); (a^m)^n = a^(mn); a^m b^m = (ab)^m; a^0 = 1; a^(-n) = 1/a^n; a^(1/n) is the nth root of a.
## Deep dive: polynomials
**Definition.** A polynomial in x is a sum of terms a x^n with whole-number powers n. Its degree is the highest power. Types by degree: constant (0), linear (1), quadratic (2), cubic (3). By number of terms: monomial, binomial, trinomial. x + 1/x and sqrt x + 3 are NOT polynomials.
**Zeroes.** A zero of p(x) is a number a with p(a) = 0. A linear polynomial a x + b has exactly one zero, -b/a. A polynomial of degree n has at most n zeroes. Graphically, the zeroes are where the graph meets the x-axis.
**Remainder theorem.** When p(x) is divided by (x - a) the remainder is p(a). When divided by (a x + b) the remainder is p(-b/a).
**Factor theorem.** (x - a) is a factor of p(x) if and only if p(a) = 0. To factorise a cubic, guess a zero among the factors of the constant term (+/-1, +/-2, ...), divide, then factorise the quadratic.
**Identities.** (a + b)^2 = a^2 + 2ab + b^2; (a - b)^2 = a^2 - 2ab + b^2; a^2 - b^2 = (a + b)(a - b); (x + a)(x + b) = x^2 + (a + b)x + ab; (a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ca; (a + b)^3 = a^3 + b^3 + 3ab(a + b); (a - b)^3 = a^3 - b^3 - 3ab(a - b); a^3 + b^3 = (a + b)(a^2 - ab + b^2); a^3 - b^3 = (a - b)(a^2 + ab + b^2); if a + b + c = 0 then a^3 + b^3 + c^3 = 3abc.
