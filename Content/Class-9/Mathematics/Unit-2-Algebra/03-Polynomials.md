# Polynomials
minutes: 40
yt: class 9 maths polynomials
@study
A polynomial is an expression with whole-number powers of a variable. Its degree is the highest power. A zero is a value that makes the polynomial zero. By the remainder theorem p(x) divided by (x - a) leaves p(a), and by the factor theorem (x - a) is a factor if p(a) = 0. Algebraic identities help in expansion and factorising.
## Deep dive: polynomials and their zeroes
A polynomial in x has the form a_n x^n + ... + a_1 x + a_0 with whole-number powers. The degree is the highest power; polynomials of degree 0, 1, 2, 3 are constant, linear, quadratic and cubic. A polynomial of degree n has at most n zeroes. The zero of a x + b is -b/a. Graphically, zeroes are the x-intercepts.
## Deep dive: remainder and factor theorems
When p(x) is divided by x - a, the remainder is p(a). So p(a) = 0 means x - a is a factor. To factorise a cubic, test small integer values that divide the constant term, divide to get a quadratic and factorise it by splitting the middle term.
## Deep dive: identities
(a + b)^2 = a^2 + 2ab + b^2; (a - b)^2 = a^2 - 2ab + b^2; a^2 - b^2 = (a + b)(a - b); (x + a)(x + b) = x^2 + (a + b)x + ab; (a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2bc + 2ca; (a + b)^3 = a^3 + b^3 + 3ab(a + b); (a - b)^3 = a^3 - b^3 - 3ab(a - b); a^3 + b^3 = (a + b)(a^2 - ab + b^2); a^3 - b^3 = (a - b)(a^2 + ab + b^2). If a + b + c = 0 then a^3 + b^3 + c^3 = 3abc. These identities speed up arithmetic, such as 103^2 = (100 + 3)^2.
