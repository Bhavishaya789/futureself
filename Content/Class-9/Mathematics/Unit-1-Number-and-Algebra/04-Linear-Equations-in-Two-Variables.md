# Linear equations in two variables
minutes: 25
yt: class 9 linear equations in two variables
@study
An equation ax + by + c = 0 with a and b not both zero is a linear equation in two variables. It has infinitely many solutions; each solution is a point on its straight-line graph.
## Deep dive: solutions and graph
The standard form is ax + by + c = 0. Every pair (x, y) that makes both sides equal is a solution, and there are infinitely many of them. To draw the graph, find at least two (preferably three) solutions, plot them and join with a straight line; the third point checks your work. Every point on the line is a solution and every solution is on the line.
## Deep dive: special lines
y = 0 is the x-axis and x = 0 is the y-axis. x = k is a vertical line parallel to the y-axis at distance k; y = k is a horizontal line parallel to the x-axis. y = mx passes through the origin. In one variable, x = 3 has one solution (a point on the number line), but in two variables it represents a line.
## Deep dive: making equations
To find k so that (a, b) lies on px + qy + k = 0, substitute x = a and y = b. Equations modelling cost, distance and age problems are written in two variables and have infinitely many solutions when no second condition is given.
