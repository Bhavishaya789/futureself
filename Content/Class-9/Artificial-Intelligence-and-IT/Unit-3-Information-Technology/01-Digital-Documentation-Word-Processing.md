# Digital documentation (word processing)
minutes: 35
yt: class 9 word processing writer
@study
A word processor (MS Word, LibreOffice Writer, Google Docs) is software to create, edit, format, save and print documents. Basic steps: type text, select, cut, copy, paste, format (font, size, bold, italic, underline, alignment), insert pictures, tables and page numbers, check spelling, save and print. Useful shortcuts: Ctrl+C copy, Ctrl+X cut, Ctrl+V paste, Ctrl+Z undo, Ctrl+S save, Ctrl+B bold, Ctrl+I italic, Ctrl+U underline.
## Deep dive: creating and saving a document
Open the word processor, a blank document appears with a title bar, menu bar, toolbars, ruler, the typing area and the status bar. Type the text; the blinking cursor shows the place of typing. Save with File > Save (Ctrl+S) giving a file name and location; Save As makes a copy under a new name or format (.docx, .odt, .pdf). Print with File > Print (Ctrl+P) after Print Preview.
## Deep dive: editing and formatting text
Select text by dragging or Shift with arrow keys; double click selects a word, triple click a line or paragraph, Ctrl+A selects all. Edit with Cut, Copy, Paste, Undo, Redo and Find and Replace. Character formatting: font name, font size, bold, italic, underline, strike-through, subscript, superscript, colour and highlight. Paragraph formatting: left, centre, right, justify alignment, line spacing, indent, bullets and numbering.
## Deep dive: inserting objects and page layout
Insert pictures, shapes, tables (rows and columns), hyperlinks, page numbers, headers and footers, date and symbols. A table cell is the box where a row and column meet; cells can be merged or split. Page setup: margins, orientation (portrait or landscape), paper size, columns and page borders. Styles such as Heading 1 give a consistent look and help make a table of contents.
## Deep dive: reviewing and sharing
Spelling and grammar check shows errors with a red or green wavy line. Word count shows words and characters. Mail merge makes many letters from one template and a list of names. Documents can be shared as PDF, printed, e-mailed or stored in cloud services such as Google Docs, where several people can edit together. Protect important files with passwords and keep backups.
