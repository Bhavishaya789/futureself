# Web applications and security
minutes: 35
yt: class 9 web applications and security
@study
A web application runs in a browser and uses the internet (Gmail, Google Docs, online banking, e-commerce). A web page has a URL, is written in HTML and is served by a web server. Security protects users: strong passwords, antivirus, firewall, updates, safe browsing (https) and care with personal data. Threats include viruses, worms, trojans, spyware, ransomware, phishing and hacking.
## Deep dive: the web and web applications
The internet is the global network; the World Wide Web (WWW) is the service of linked web pages. A web page is written in HTML and may use CSS (style) and JavaScript (action). A website is a set of related pages with a home page. A URL (https://www.example.com/page) has a protocol, domain name and path. A web server stores sites and sends pages to a browser (client). A web application (web app) is software used through a browser: e-mail, online forms, maps, e-commerce, net banking, online classes and cloud documents. Cloud computing stores and processes data on internet servers.
## Deep dive: e-mail, social media and online services
E-mail uses addresses of the form name@domain. Social media (Instagram, YouTube, WhatsApp) lets people share content; think before you post because posts can stay forever. E-commerce is buying and selling online (Amazon, Flipkart); e-governance gives government services online (DigiLocker, UMANG); online payment uses UPI, cards or net banking and needs extra care. A blog is a website of regularly posted articles.
## Deep dive: threats to security
Malware is harmful software. A virus attaches to files and spreads when they are opened; a worm spreads by itself through networks; a trojan pretends to be useful software; spyware secretly watches your activity; ransomware locks files and demands money; adware shows unwanted advertisements. Phishing tricks people with fake messages or sites. Hacking is unauthorised access to a system. Identity theft is stealing personal details. Cyberbullying and online fraud are other risks.
## Deep dive: staying safe
Use a strong, unique password (long, with upper and lower case letters, digits and symbols) and two-factor authentication (OTP). Install antivirus and a firewall, keep software updated, download only from trusted sources and avoid public Wi-Fi for banking. Check that a site uses https with a padlock. Do not share OTP, PIN, passwords or personal information. Report cyber crime at cybercrime.gov.in or helpline 1930. Respect copyright and do not plagiarise. Be kind online.
