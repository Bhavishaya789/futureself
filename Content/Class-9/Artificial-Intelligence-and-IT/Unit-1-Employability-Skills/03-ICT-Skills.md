# ICT skills
minutes: 35
yt: class 9 ict skills
@study
ICT (Information and Communication Technology) covers devices and tools used to store, process and share information: computers, phones, the internet and software. Basic ICT skills include using a keyboard and mouse, word processing, spreadsheets, e-mail, browsing and online safety. Hardware is the physical part of a computer; software is the set of programs. Input devices (keyboard, mouse) send data in; output devices (monitor, printer) show results; the CPU processes data; memory and storage hold it.
## Deep dive: computer hardware
A computer has input devices (keyboard, mouse, scanner, microphone, webcam), a processing unit (CPU, the brain), memory (RAM is temporary and fast; ROM is permanent), storage (hard disk, SSD, pen drive) and output devices (monitor, printer, speakers). The CPU has an ALU for arithmetic and logic and a control unit that directs operations. Data size: 1 byte = 8 bits; 1 KB = 1024 bytes; 1 MB = 1024 KB; 1 GB = 1024 MB; 1 TB = 1024 GB.
## Deep dive: software and operating systems
Software is of two kinds: system software (operating system such as Windows, Linux, Android; utilities; drivers) and application software (word processor, spreadsheet, browser, games). The operating system manages hardware, files, memory and programs and provides the user interface. A file has a name and an extension (.docx, .xlsx, .jpg, .pdf, .mp3) that shows its type. Folders organise files.
## Deep dive: the internet and e-mail
The internet is a global network of computers. The World Wide Web is a collection of web pages reached with a browser (Chrome, Edge, Firefox) using a URL. A search engine (Google, Bing) finds information. E-mail has an address (name@domain), fields To, Cc, Bcc, Subject and Attachment. Safe use: strong passwords, no sharing of personal data, avoiding unknown links, logging out of shared computers.
## Deep dive: digital citizenship
Cyber safety means using technology responsibly. Cyberbullying is harassing others online; plagiarism is copying work without credit; copyright protects an author's work. Phishing tricks people into giving passwords. A strong password has upper and lower case letters, digits and symbols. Antivirus software protects against viruses and malware. Backing up data avoids loss.
