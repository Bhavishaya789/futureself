@study
Trigonometric functions are not one-one over their full domains, so their inverses are defined by restricting the domain to an interval where they are bijective. The principal value branches are: sin inverse x has domain [-1, 1] and range [-pi/2, pi/2]; cos inverse x has domain [-1, 1] and range [0, pi]; tan inverse x has domain R and range (-pi/2, pi/2); cot inverse x has domain R and range (0, pi); sec inverse x has domain R minus (-1, 1) and range [0, pi] minus {pi/2}; cosec inverse x has domain R minus (-1, 1) and range [-pi/2, pi/2] minus {0}. The graph of an inverse function is the reflection of the original graph in the line y = x. Important identities: sin inverse(sin x) = x for x in [-pi/2, pi/2], and sin(sin inverse x) = x for x in [-1, 1]; sin inverse(-x) = - sin inverse x, cos inverse(-x) = pi - cos inverse x, tan inverse(-x) = - tan inverse x; sin inverse x + cos inverse x = pi/2 for x in [-1, 1]; tan inverse x + cot inverse x = pi/2 for real x; sec inverse x + cosec inverse x = pi/2 for modulus of x at least 1. Further, sin inverse(1/x) = cosec inverse x, cos inverse(1/x) = sec inverse x and tan inverse(1/x) = cot inverse x for suitable x. Sum and difference: tan inverse x + tan inverse y = tan inverse((x + y)/(1 - xy)) when xy < 1, and tan inverse x - tan inverse y = tan inverse((x - y)/(1 + xy)) when xy > -1. Also 2 tan inverse x = sin inverse(2x/(1 + x^2)) for modulus of x at most 1, 2 tan inverse x = cos inverse((1 - x^2)/(1 + x^2)) for x at least 0, and 2 tan inverse x = tan inverse(2x/(1 - x^2)) for modulus of x less than 1. Values to remember: sin inverse(1/2) = pi/6, cos inverse(1/2) = pi/3, tan inverse(1) = pi/4, and cos inverse(-1/2) = 2 pi/3. The principal value is the value of the function within the chosen range.
