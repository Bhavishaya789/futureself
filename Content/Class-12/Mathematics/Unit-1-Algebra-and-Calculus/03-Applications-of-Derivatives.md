@study
**Maxima and minima:** at a stationary point f'(x) = 0; if f''(x) > 0 it is a minimum, if f''(x) < 0 a maximum. Example: f(x) = x^3 - 3x: f' = 3x^2 - 3 = 0 at x = +/-1; f'' = 6x so x = 1 is a **minimum** (f = -2) and x = -1 a maximum (f = 2).
**Increasing/decreasing:** f' > 0 increasing. **Tangent:** slope at a point is f'(a); **rate of change:** dV/dt = (dV/dr)(dr/dt).
**Optimisation:** a rectangle of fixed perimeter has the largest area when it is a square.
