# Applications of Derivatives

@study
The derivative dy/dx measures the rate of change of y with respect to x. If a quantity y varies with time t, dy/dt is its rate of change; by the chain rule dy/dt = (dy/dx)(dx/dt). Examples include the rate of change of the area of a circle, A = pi r^2, giving dA/dt = 2 pi r dr/dt, and of the volume of a sphere, V = (4/3) pi r^3, giving dV/dt = 4 pi r^2 dr/dt. A function f is increasing on an interval if f′(x) > 0 and decreasing if f′(x) < 0 on the interval; it is strictly increasing if x1 < x2 gives f(x1) < f(x2). The slope of the tangent to y = f(x) at (x0, y0) is f′(x0), so the tangent is y - y0 = f′(x0)(x - x0). The normal is perpendicular to the tangent with slope -1/f′(x0), so its equation is y - y0 = (-1/f′(x0))(x - x0). Tangent and normal are parallel to the x-axis when the slope is zero or vertical, and the angle between a curve and a line can be found from slopes. Approximations use differentials: dy = f′(x) dx, and f(x + delta x) is approximately f(x) + f′(x) delta x. Maxima and minima: a point c is a critical point if f′(c) = 0 or f′(c) does not exist. The first derivative test says that if f′ changes sign from positive to negative at c, c is a local maximum, and from negative to positive a local minimum; if no sign change, it is a point of inflexion. The second derivative test says that if f′(c) = 0 and f″(c) < 0, then c is a local maximum, if f″(c) > 0 a local minimum, and if f″(c) = 0 the test fails. The absolute maximum and minimum of a continuous function on a closed interval [a, b] occur at critical points or at the end points. Word problems on optimisation include the maximum area of a rectangle of given perimeter, which is a square, the maximum volume of an open box formed from a square sheet, and the closed cylinder of fixed volume with minimum surface area, which has height equal to the diameter.
## Deep dive: Rate and monotonicity
Rate of change uses the chain rule; the sign of f′ shows increasing or decreasing behaviour.
## Deep dive: Tangent, normal and approximation
The tangent has slope f′(x0); differentials estimate small changes.
## Deep dive: Maxima and minima
Use first or second derivative tests, and check endpoints for absolute extrema on closed intervals.
