@study
A relation R from a set A to a set B is a subset of the Cartesian product A x B. A relation on A is a subset of A x A. The empty relation has no pair and the universal relation contains all pairs. A relation R on A is reflexive if (a, a) is in R for every a, symmetric if (a, b) in R implies (b, a) in R, and transitive if (a, b) and (b, c) in R imply (a, c) in R. A relation that is reflexive, symmetric and transitive is an equivalence relation, and it partitions the set into disjoint equivalence classes. A function f from A to B assigns to each element of A exactly one element of B; A is the domain, B the codomain and the set of images is the range. A function is one-one (injective) if different elements have different images, and onto (surjective) if every element of B is an image. A function that is both is bijective. For finite sets, a function from A to A is one-one if and only if it is onto. If A has m elements and B has n elements, the number of functions is n^m, the number of relations is 2^(mn), and the number of one-one functions is nPm when n is at least m. The number of bijections from a set of n elements to itself is n factorial. The composition of f: A to B and g: B to C is gof(x) = g(f(x)). Composition is associative but not commutative. A function is invertible if and only if it is bijective, and then fog = I and gof = I for its inverse. The inverse of a bijection is also a bijection, and (gof) inverse equals f inverse o g inverse. A binary operation on a set A is a function from A x A to A. It is commutative if a * b = b * a and associative if (a * b) * c = a * (b * c). An identity element e satisfies a * e = e * a = a, and an inverse of a satisfies a * b = e. Examples to verify are the relation of congruence modulo and the relation of being in the same line.
## Deep dive: Types of relations
Reflexive, symmetric and transitive properties combine to define equivalence relations, which partition a set.
## Deep dive: Types of functions
One-one, onto and bijective functions decide invertibility; counting rules give the number of functions.
## Deep dive: Composition and operations
Composition is associative, the inverse of gof is f inverse o g inverse, and binary operations may have identity and inverse.

## High
P: Show that the relation R = {(a, b): a - b is divisible by 3} on integers is an equivalence relation.
A: Reflexive since a - a = 0, symmetric since b - a is a multiple of 3 and transitive since sums of multiples of 3 are multiples of 3.
