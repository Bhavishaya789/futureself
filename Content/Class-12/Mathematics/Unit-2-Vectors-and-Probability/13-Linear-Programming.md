# Linear Programming
minutes: 45
yt: class 12 maths linear programming objective function constraints feasible region corner point method
@study
Linear programming deals with optimising a linear objective function subject to linear inequalities called constraints. The objective function Z = ax + by is to be maximised or minimised, the variables x and y are called decision variables, and non-negativity restrictions x >= 0, y >= 0 apply. The feasible region is the common region determined by all constraints, including non-negativity. Points inside the region are feasible solutions; points outside are infeasible. A feasible solution that optimises the objective function is an optimal solution. The corner point theorem says that if the feasible region is bounded, the objective function has both a maximum and minimum at corner points. If the region is unbounded, a maximum or minimum may not exist; if the maximum (or minimum) exists it occurs at a corner point. For an unbounded region, draw the half-plane ax + by > M (for maximum) or < m (for minimum) and see if it has points in common with the feasible region; if not, M (or m) is the value. The corner point method has steps: formulate the problem mathematically, graph constraints, identify the feasible region, find corner points by solving boundary equations, compute Z at each corner and select the largest or smallest. If two corner points give the same optimal value, every point on the line segment joining them is also optimal, so there are infinitely many solutions. Typical problems include diet problems, which minimise cost subject to nutrient requirements, manufacturing problems that maximise profit under limited machine time and raw material, and transportation problems. The graph of a linear inequality is a half-plane, determined by testing a point such as the origin. A bounded region is enclosed within a circle, while an unbounded region extends indefinitely. An empty feasible region means there is no solution.
## Deep dive: Formulation
Define variables, write the objective function and list the constraints with non-negativity conditions.
## Deep dive: Corner point method
Graph the feasible region, find corner points and evaluate Z at each to find the optimum.
## Deep dive: Special cases
Unbounded regions need extra checks, and two optimal corners give infinitely many optimal solutions.
