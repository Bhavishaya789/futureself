# Computer Networks
minutes: 45
yt: class 12 computer science networks lan wan topology switch router ip dns url protocol
@study
A computer network is a set of interconnected devices that share resources and data. Types by size: PAN (personal area), LAN (local area, within a building), MAN (metropolitan, a city) and WAN (wide area, countries; the Internet is the largest WAN). Network devices: NIC (network interface card, with a unique MAC address), hub (broadcasts to all ports), switch (forwards to the intended port using MAC addresses), repeater (regenerates signals), bridge (connects two LANs), router (connects different networks and forwards packets using IP addresses), gateway (connects networks with different protocols) and modem (modulates and demodulates signals between digital and analogue). Topologies: bus (single backbone cable; cheap but a break fails the network), star (central hub or switch; easy to manage, but the centre is a point of failure), ring (each node connected to two others), mesh (every node connected to every other; reliable but costly) and tree (hierarchy of stars). Network types by architecture: client-server and peer-to-peer. Identification: IP address (IPv4 32 bits, like 192.168.1.1; IPv6 128 bits), MAC address (48 bits, burned into the NIC), domain name and URL. DNS (Domain Name System) translates domain names to IP addresses. Protocols are rules for communication: TCP/IP (reliable delivery, the Internet suite), HTTP and HTTPS (web), FTP (file transfer), SMTP, POP3 and IMAP (email), Telnet and SSH (remote login), VoIP (voice over IP), PPP. The web: a web page is a document; a website is a collection of pages; a browser such as Chrome displays them; a web server hosts them; URL: protocol://domain/path. Cloud computing offers services over the Internet: IaaS, PaaS and SaaS. Internet of Things connects smart devices. Wi-Fi, Bluetooth and NFC are wireless technologies; cellular generations are 2G to 5G.
## Deep dive: Types and topologies
LAN, MAN and WAN differ by area; bus, star, ring, mesh and tree differ in layout and fault tolerance.
## Deep dive: Devices
A switch uses MAC addresses within a LAN; a router uses IP addresses between networks; a gateway translates protocols.
## Deep dive: Addressing
IP addresses identify hosts on a network, MAC addresses identify hardware and DNS maps names to IP.
