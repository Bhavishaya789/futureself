# Electrostatics: Coulomb's law and electric field
minutes: 20

@study
**Charge** is quantised (q = n e, e = 1.6 x 10^-19 C) and conserved.
**Coulomb's law:** F = k q1 q2 / r^2 with k = 9 x 10^9 N m^2/C^2 (k = 1/4 pi e0). Example: 2 uC and 3 uC at 0.3 m: F = 9e9 x 6e-12 / 0.09 = **0.6 N** (repulsive).
**Electric field** E = F / q = k Q / r^2 (point charge). Field lines start on positive and end on negative charges and never cross.
**Gauss's law:** flux = Q_enclosed / e0. Field of an infinite sheet is sigma / (2 e0); inside a conductor E = 0.
**Potential** V = k Q / r; work to move charge W = q dV. **Capacitor:** C = Q / V; parallel plate C = e0 A / d; energy U = (1/2) C V^2. Series: 1/C = 1/C1 + 1/C2; parallel: C = C1 + C2.
