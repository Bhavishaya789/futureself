# Introduction to Computer Networks

@study
A computer network is a set of interconnected devices that share data and resources. ARPANET, started in 1969, was the first major network and led to the Internet. Networks are classified by size: PAN covers a person’s devices, LAN a building or campus, MAN a city and WAN a large area such as a country; the Internet is a network of networks. Topology is the arrangement of nodes: bus uses a single backbone cable, star connects nodes to a central hub or switch, ring connects nodes in a loop, tree is a hierarchy of stars, and mesh connects nodes to many others. Star is common because a failure of one node does not affect others, but the central device is a single point of failure. Devices include the modem, which converts digital to analogue signals and back, hub, which broadcasts to all ports, switch, which forwards to the intended port, router, which connects networks and routes packets, repeater, which regenerates signals, and gateway, which connects different network types. Media may be wired (twisted pair, coaxial, optical fibre) or wireless (radio waves, microwave, infrared, satellite, Wi-Fi, Bluetooth). Every device has a 48-bit MAC address. An IP address identifies a device on a network: IPv4 is 32 bits and IPv6 is 128 bits. The Domain Name System (DNS) translates domain names to IP addresses. A URL is the address of a web resource. Protocols are rules for communication: HTTP and HTTPS for web pages, FTP for file transfer, SMTP, POP3 and IMAP for email, TCP/IP for the Internet, and VoIP for voice. The World Wide Web, invented by Tim Berners-Lee, is a service on the Internet. Bandwidth is the data capacity of a link, measured in bits per second. Cloud computing and the Internet of Things are modern trends.
## Deep dive: Types and topologies
PAN, LAN, MAN and WAN differ by size; bus, star, ring, tree and mesh differ by layout.
## Deep dive: Devices and media
Modems, hubs, switches, routers, repeaters and gateways connect devices over wired or wireless media.
## Deep dive: Addresses and protocols
IP and MAC addresses identify devices, DNS maps names, and protocols like HTTP, SMTP and FTP define communication.

## Moderate
P: Differentiate a hub and a switch.

P: Compare star and bus topologies.
A: Star connects all nodes to a central device and tolerates node failure but depends on the hub, while bus uses one backbone whose failure stops the network.
