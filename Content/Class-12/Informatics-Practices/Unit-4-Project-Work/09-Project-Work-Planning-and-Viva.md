# Project Work: Planning, Development and Viva
minutes: 45

@study
The Informatics Practices project applies skills learned in the course to a real problem. A good project follows stages: identify a problem, collect or choose a dataset, plan the design, develop the solution, test it and document the work. Typical project themes include analysis of student marks, sales data, weather records or health statistics. The data may be stored in a CSV file or MySQL database. Using Python, data is loaded into a Pandas DataFrame, cleaned by handling missing values and duplicates, and analysed using statistics, sorting, filtering and groupby. Results are visualised using Matplotlib charts such as line, bar and histogram, with titles, labels and legends. A database-based project uses SQL for queries, with tables and keys properly designed. The software development life cycle includes analysis, design, coding, testing, deployment and maintenance. The project report generally contains a title page, certificate, acknowledgement, index, introduction, objectives, system requirements, hardware and software used, source code with comments, sample output, conclusion, future scope and bibliography. Good coding practice involves meaningful variable names, comments, functions and modular design. Testing checks that the program gives correct results for normal and boundary inputs. During the viva, students are asked about the problem, dataset, libraries used, functions, queries and results. Honest citation of data sources and avoiding plagiarism are essential. Team projects need clear division of work and version control helps manage code. A project should be original, relevant and well documented.
## Deep dive: Project stages
Identify a problem, choose data, design, code, test and document the work step by step.
## Deep dive: Technical content
Use Pandas for cleaning and analysis, Matplotlib for charts and SQL for database queries.
## Deep dive: Report and viva
The report documents the work; viva questions test understanding of data, code and results.
