# ஆயத்தொலை வடிவியல், வட்டம் மற்றும் வடிவொத்த முக்கோணங்கள்
@study
**தூர சூத்திரம்:** d = √((x2 - x1)² + (y2 - y1)²); எ.கா. (0, 0) முதல் (3, 4) வரை தூரம் **5**. **பிரிவு சூத்திரம்:** (x1, y1), (x2, y2) புள்ளிகளை m:n விகிதத்தில் பிரிக்கும் புள்ளி = ((m x2 + n x1)/(m + n), (m y2 + n y1)/(m + n)); m = n ஆனால் அது நடுப்புள்ளி. முக்கோணத்தின் பரப்பு = (1/2)|x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)|.
**வடிவொத்த முக்கோணங்கள்:** ஒத்த பக்கங்கள் ஒரே விகிதத்தில்; பரப்புகளின் விகிதம் பக்கங்களின் வர்க்க விகிதம். **வட்டம்:** தொடுகோடு தொடுபுள்ளியில் ஆரத்துக்குச் செங்குத்து; வெளிப்புள்ளியிலிருந்து வரையும் தொடுகோடுகள் சமம். தொடுகோட்டின் நீளம் 12, ஆரம் 5 எனில் மையத்திலிருந்து தூரம் √(144 + 25) = **13**.
> வெளிப்புள்ளியிலிருந்து வரையும் தொடுகோடுகளின் நீளம் சமம்.
