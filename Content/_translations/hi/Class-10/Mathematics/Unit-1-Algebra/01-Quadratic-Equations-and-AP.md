# द्विघात समीकरण और समांतर श्रेढ़ी
@study
**द्विघात समीकरण** a x² + b x + c = 0 के मूल x = (-b ± √D) / 2a होते हैं, जहाँ विविक्तकर D = b² - 4ac। D > 0 हो तो दो भिन्न वास्तविक मूल; D = 0 हो तो समान मूल; D < 0 हो तो कोई वास्तविक मूल नहीं। उदाहरण: 2x² - 7x + 3 = 0: D = 49 - 24 = 25, मूल **3** और **0.5**। मूलों का योग = -b/a; गुणनफल = c/a।
**समांतर श्रेढ़ी (AP):** a_n = a + (n - 1) d; S_n = n/2 [2a + (n - 1) d]। 2, 5, 8, ... के लिए: S_20 = 10 (4 + 57) = **610**।
> पहले विविक्तकर देखिए।
@qa
Q: 2x² - 7x + 3 का विविक्तकर?
A: 25।
Q: 2x² - 7x + 3 = 0 के मूल?
A: 3 और 1/2।
Q: D = 0 होने पर मूलों की प्रकृति?
A: वास्तविक और समान।
Q: 2, 5, 8, ... के प्रथम 20 पदों का योग?
A: 610।
