# संख्या पद्धति और बहुपद
@study
**संख्या पद्धति:** प्राकृत, पूर्ण, पूर्णांक, परिमेय (p/q), अपरिमेय (अनंत और अनावर्ती दशमलव, जैसे √2 और π), वास्तविक संख्याएँ। प्रत्येक परिमेय संख्या का दशमलव सांत या आवर्ती होता है।
**बहुपद:** a x^n + ... + c जैसा व्यंजक। घात सबसे बड़ी घात होती है। **शेषफल प्रमेय:** p(x) को (x - a) से भाग देने पर शेषफल p(a) होता है। **गुणनखंड प्रमेय:** यदि p(a) = 0 हो तो (x - a), p(x) का एक गुणनखंड है।
सर्वसमिकाएँ: (a + b)² = a² + 2ab + b²; (a - b)² = a² - 2ab + b²; a² - b² = (a + b)(a - b); (a + b)³ = a³ + b³ + 3ab(a + b)।
उदाहरण: x² - 5x + 6 = (x - 2)(x - 3), क्योंकि 2 + 3 = 5 और 2 x 3 = 6।
> n घात वाले बहुपद के अधिकतम n मूल होते हैं।

Q: गुणनखंड प्रमेय बताइए।
A: (x - a), p(x) का गुणनखंड तभी होता है जब p(a) = 0 हो।
Q: क्या √2 परिमेय है?
A: नहीं, यह अपरिमेय है।
Q: x² - 5x + 6 के गुणनखंड कीजिए।
A: (x - 2)(x - 3)।
Q: 3x⁴ + 2x की घात क्या है?
A: 4।
