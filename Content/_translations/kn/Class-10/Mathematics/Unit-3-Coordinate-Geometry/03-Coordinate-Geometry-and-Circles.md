# ನಿರ್ದೇಶಾಂಕ ರೇಖಾಗಣಿತ, ವೃತ್ತ ಮತ್ತು ಸಮರೂಪ ತ್ರಿಭುಜಗಳು
@study
**ದೂರ ಸೂತ್ರ:** d = √((x2 - x1)² + (y2 - y1)²); ಉದಾ. (0, 0) ರಿಂದ (3, 4) ವರೆಗಿನ ದೂರ **5**. **ವಿಭಜನಾ ಸೂತ್ರ:** (x1, y1) ಮತ್ತು (x2, y2) ಬಿಂದುಗಳನ್ನು m:n ಅನುಪಾತದಲ್ಲಿ ವಿಭಾಗಿಸುವ ಬಿಂದು = ((m x2 + n x1)/(m + n), (m y2 + n y1)/(m + n)); m = n ಆದರೆ ಅದು ಮಧ್ಯಬಿಂದು. ತ್ರಿಭುಜದ ವಿಸ್ತೀರ್ಣ = (1/2)|x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)|.
**ಸಮರೂಪ ತ್ರಿಭುಜಗಳು:** ಅನುರೂಪ ಭುಜಗಳು ಒಂದೇ ಅನುಪಾತದಲ್ಲಿರುತ್ತವೆ; ವಿಸ್ತೀರ್ಣಗಳ ಅನುಪಾತ ಭುಜಗಳ ವರ್ಗಗಳ ಅನುಪಾತಕ್ಕೆ ಸಮ. **ವೃತ್ತ:** ಸ್ಪರ್ಶಕವು ಸ್ಪರ್ಶ ಬಿಂದುವಿನಲ್ಲಿ ತ್ರಿಜ್ಯಕ್ಕೆ ಲಂಬವಾಗಿರುತ್ತದೆ; ಹೊರಗಿನ ಬಿಂದುವಿನಿಂದ ಎಳೆದ ಸ್ಪರ್ಶಕಗಳು ಸಮ. ಸ್ಪರ್ಶಕದ ಉದ್ದ 12 ಮತ್ತು ತ್ರಿಜ್ಯ 5 ಆದರೆ ಕೇಂದ್ರದಿಂದ ದೂರ √(144 + 25) = **13**.
> ಹೊರಗಿನ ಬಿಂದುವಿನಿಂದ ಎಳೆದ ಸ್ಪರ್ಶಕಗಳ ಉದ್ದ ಸಮ.
