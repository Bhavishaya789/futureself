# నిరూపక జ్యామితి, వృత్తాలు మరియు సరూప త్రిభుజాలు
@study
**దూర సూత్రం:** d = √((x2 - x1)² + (y2 - y1)²); ఉదా. (0, 0) నుండి (3, 4) వరకు దూరం **5**. **విభజన సూత్రం:** (x1, y1), (x2, y2) బిందువులను m:n నిష్పత్తిలో విభజించే బిందువు = ((m x2 + n x1)/(m + n), (m y2 + n y1)/(m + n)); m = n అయితే అది మధ్య బిందువు. త్రిభుజ వైశాల్యం = (1/2)|x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)|.
**సరూప త్రిభుజాలు:** సంబంధిత భుజాలు ఒకే నిష్పత్తిలో ఉంటాయి; వైశాల్యాల నిష్పత్తి భుజాల వర్గాల నిష్పత్తికి సమానం. **వృత్తం:** స్పర్శరేఖ స్పర్శ బిందువు వద్ద వ్యాసార్ధానికి లంబంగా ఉంటుంది; బాహ్య బిందువు నుండి గీసిన స్పర్శరేఖలు సమానం. స్పర్శరేఖ పొడవు 12, వ్యాసార్ధం 5 అయితే కేంద్రం నుండి దూరం √(144 + 25) = **13**.
> బాహ్య బిందువు నుండి గీసిన స్పర్శరేఖల పొడవులు సమానం.
