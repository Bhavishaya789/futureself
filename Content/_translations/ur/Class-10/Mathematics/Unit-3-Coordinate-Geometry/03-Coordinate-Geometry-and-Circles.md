# محدد جیومیٹری، دائرے اور مماثل مثلثیں
@study
**فاصلے کا کلیہ:** d = √((x2 - x1)² + (y2 - y1)²)؛ مثلاً (0, 0) سے (3, 4) تک فاصلہ **5** ہے۔ **تقسیم کا کلیہ:** (x1, y1) اور (x2, y2) کو m:n کی نسبت سے تقسیم کرنے والا نقطہ = ((m x2 + n x1)/(m + n), (m y2 + n y1)/(m + n))؛ m = n ہو تو یہ وسطی نقطہ ہے۔ مثلث کا رقبہ = (1/2)|x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)|۔
**مماثل مثلثیں:** متناظر اضلاع ایک ہی نسبت میں ہوتے ہیں؛ رقبوں کی نسبت اضلاع کے مربعوں کی نسبت کے برابر ہوتی ہے۔ **دائرہ:** مماس نقطۂ تماس پر رداس پر عمود ہوتا ہے؛ بیرونی نقطے سے کھینچے گئے مماس برابر ہوتے ہیں۔ مماس کی لمبائی 12 اور رداس 5 ہو تو مرکز سے فاصلہ √(144 + 25) = **13** ہے۔
> بیرونی نقطے سے کھینچے گئے مماسوں کی لمبائی برابر ہوتی ہے۔
