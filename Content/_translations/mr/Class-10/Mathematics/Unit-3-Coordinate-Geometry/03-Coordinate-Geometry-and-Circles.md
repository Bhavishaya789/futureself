# निर्देशक भूमिती, वर्तुळ आणि समरूप त्रिकोण
@study
**अंतर सूत्र:** d = √((x2 - x1)² + (y2 - y1)²); उदा. (0, 0) ते (3, 4) अंतर **5**. **विभाजन सूत्र:** (x1, y1) आणि (x2, y2) यांना m:n गुणोत्तरात विभागणारा बिंदू = ((m x2 + n x1)/(m + n), (m y2 + n y1)/(m + n)); मध्यबिंदू म्हणजे m = n ही स्थिती. त्रिकोणाचे क्षेत्रफळ = (1/2)|x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)|.
**समरूप त्रिकोण:** संगत बाजू समान गुणोत्तरात; क्षेत्रफळांचे गुणोत्तर बाजूंच्या वर्गांच्या गुणोत्तराइतके. **वर्तुळ:** स्पर्शिका स्पर्शबिंदूत त्रिज्येला लंब असते; बाह्य बिंदूपासून काढलेल्या स्पर्शिका समान असतात. स्पर्शिकेची लांबी 12 आणि त्रिज्या 5 असल्यास केंद्रापासून अंतर √(144 + 25) = **13**.
> बाह्य बिंदूपासून काढलेल्या स्पर्शिकांची लांबी समान असते.
