# યામ ભૂમિતિ, વર્તુળ અને સમરૂપ ત્રિકોણ
@study
**અંતર સૂત્ર:** d = √((x2 - x1)² + (y2 - y1)²); દા.ત. (0, 0) થી (3, 4) સુધીનું અંતર **5**. **વિભાજન સૂત્ર:** (x1, y1) અને (x2, y2) ને m:n ગુણોત્તરમાં વહેંચતો બિંદુ = ((m x2 + n x1)/(m + n), (m y2 + n y1)/(m + n)); m = n હોય ત્યારે તે મધ્યબિંદુ. ત્રિકોણનું ક્ષેત્રફળ = (1/2)|x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)|.
**સમરૂપ ત્રિકોણ:** અનુરૂપ બાજુઓ સમાન ગુણોત્તરમાં; ક્ષેત્રફળનો ગુણોત્તર બાજુઓના વર્ગના ગુણોત્તર જેટલો. **વર્તુળ:** સ્પર્શક સ્પર્શબિંદુએ ત્રિજ્યાને લંબ હોય છે; બહારના બિંદુથી દોરેલા સ્પર્શકો સમાન હોય છે. સ્પર્શકની લંબાઈ 12 અને ત્રિજ્યા 5 હોય તો કેન્દ્રથી અંતર √(144 + 25) = **13**.
> બહારના બિંદુથી દોરેલા સ્પર્શકોની લંબાઈ સમાન હોય છે.
