# നിർദ്ദേശാങ്ക ജ്യാമിതി, വൃത്തം, സദൃശ ത്രികോണങ്ങൾ
@study
**ദൂര സൂത്രവാക്യം:** d = √((x2 - x1)² + (y2 - y1)²); ഉദാ. (0, 0) മുതൽ (3, 4) വരെയുള്ള ദൂരം **5**. **വിഭജന സൂത്രവാക്യം:** (x1, y1), (x2, y2) ബിന്ദുക്കളെ m:n അനുപാതത്തിൽ വിഭജിക്കുന്ന ബിന്ദു = ((m x2 + n x1)/(m + n), (m y2 + n y1)/(m + n)); m = n ആയാൽ അത് മധ്യബിന്ദു. ത്രികോണത്തിന്റെ വിസ്തീർണ്ണം = (1/2)|x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)|.
**സദൃശ ത്രികോണങ്ങൾ:** അനുബന്ധ വശങ്ങൾ ഒരേ അനുപാതത്തിലായിരിക്കും; വിസ്തീർണ്ണങ്ങളുടെ അനുപാതം വശങ്ങളുടെ വർഗ്ഗങ്ങളുടെ അനുപാതത്തിന് തുല്യം. **വൃത്തം:** സ്പർശരേഖ സ്പർശബിന്ദുവിൽ ആരത്തിന് ലംബമാണ്; പുറത്തെ ബിന്ദുവിൽ നിന്നുള്ള സ്പർശരേഖകൾ തുല്യമാണ്. സ്പർശരേഖയുടെ നീളം 12, ആരം 5 ആയാൽ കേന്ദ്രത്തിൽ നിന്നുള്ള ദൂരം √(144 + 25) = **13**.
> പുറത്തെ ബിന്ദുവിൽ നിന്നുള്ള സ്പർശരേഖകളുടെ നീളം തുല്യമാണ്.
