# Statistics: Correlation, Index Numbers and Use of Statistical Tools
minutes: 50

@study
Correlation measures the degree and direction of the linear relationship between two variables. Types: positive, negative, no correlation, linear and non-linear. Scatter diagram. Karl Pearson coefficient r = (n sum xy - sum x sum y) / sqrt((n sum x^2 - (sum x)^2)(n sum y^2 - (sum y)^2)), range -1 to +1. Spearman rank correlation rs = 1 - 6 sum d^2 / (n (n^2 - 1)). Interpretation: r close to 1 is high positive; correlation does not imply causation. Example: x = 1 to 5 and y = 2, 4, 5, 4, 5 give r = 0.7746; ranks 1,2,3,4,5 and 2,1,4,3,5 give rs = 0.8. Index numbers: relative change in a variable over time; base year = 100. Price index: Laspeyres (base year quantities) = sum p1q0 / sum p0q0 x 100; Paasche (current quantities) = sum p1q1 / sum p0q1 x 100; Fisher = sqrt(L x P). Example: p0 = 10, 20; q0 = 5, 3; p1 = 12, 25; q1 = 6, 4 gives Laspeyres 122.73, Paasche 122.86, Fisher 122.79. Types: CPI, WPI, IIP, Sensex. Use of statistical tools, project work in economics.
## Deep dive: Correlation
Scatter diagram: points rising show positive; falling show negative. Karl Pearson: example x = 1, 2, 3, 4, 5; y = 2, 4, 5, 4, 5; sum x = 15; sum y = 20; sum xy = 66; sum x^2 = 55; sum y^2 = 86; numerator = 5 x 66 - 15 x 20 = 30; denominator = sqrt((275 - 225)(430 - 400)) = sqrt(50 x 30) = 38.73; r = 0.7746. Properties: unit-free, between -1 and +1, unaffected by change of origin and scale. Spearman: d = -1, 1, -1, 1, 0; sum d^2 = 4; rs = 1 - 24/120 = 0.8. Correlation is not causation (spurious).
## Deep dive: Index numbers
Index number measures changes in prices, quantities or values; weighted and unweighted. Construction: choose the base, items and prices. Simple aggregate: sum p1 / sum p0 x 100. Laspeyres uses base-year weights: sum p1q0 = 12 x 5 + 25 x 3 = 135; sum p0q0 = 50 + 60 = 110; index = 122.73. Paasche uses current-year weights: sum p1q1 = 72 + 100 = 172; sum p0q1 = 60 + 80 = 140; index = 122.86. Fisher is the geometric mean = 122.79. Consumer Price Index (CPI): cost of living; WPI: wholesale prices (in India with base 2011-12); IIP: industrial output; Sensex: 30 stocks of BSE. Inflation = (CPI_t - CPI_{t-1}) / CPI_{t-1} x 100.
## Deep dive: Uses and cautions
Uses: measure inflation, adjust wages (DA), deflate GDP, policy making. Limitations: sampling errors, base year choice, changing consumption patterns. Real wages = money wages / CPI x 100. Statistical tools in project: collect data, present with tables and diagrams, compute averages, interpret and conclude. Ethics of using statistics: avoid misleading graphs.
