# Statistics: Introduction, Collection, Organisation and Presentation of Data
minutes: 45
yt: class 11 economics statistics collection organisation presentation of data
@study
Statistics: singular (methods) and plural (data). Functions: simplification, comparison, formulation of hypothesis. Limitations. Data: primary (collected by the investigator) and secondary (published or unpublished). Methods of collecting primary data: personal interview, questionnaire/schedule, telephone, observation; census versus sample survey; sampling: random (simple, stratified, systematic) and non-random (judgement, convenience, quota); errors: sampling and non-sampling. Organisation of data: raw data, array, frequency distribution (discrete, continuous; class interval, class limits, class mark, class width), exclusive and inclusive method, cumulative frequency (less than, more than), tally marks. Presentation: tables (title, number, head note, stub, caption, body, source), diagrams (bar, multiple bar, sub-divided bar, pie chart), graphs (histogram, frequency polygon, ogive, time series line graph, frequency curve). Sources: NSSO, Census, RBI.
## Deep dive: Data collection
Census collects data from every unit (population census every 10 years); sample uses a part. Questionnaire: set of questions mailed; schedule filled by an enumerator. Sampling methods: simple random sampling (lottery, random number tables), stratified, systematic, cluster; purposive, convenience. Errors: sampling error (due to using a sample), non-sampling error (faulty design, non-response). Secondary sources: government publications, RBI bulletins, NSSO reports, Economic Survey. Pilot survey.
## Deep dive: Organisation
Class interval, e.g., 10-20; class limits 10 and 20; class mark = (upper + lower)/2 = 15; class width = upper - lower = 10; Sturges: number of classes = 1 + 3.322 log N. Exclusive (upper limit excluded) vs inclusive method. Cumulative frequency: less than type adds up from the top; more than type adds from the bottom. Example: marks 0-10, 10-20, 20-30 with frequency 5, 8, 7. Relative frequency. Tally marks in groups of five.
## Deep dive: Presentation
Table parts: table number, title, head note, caption (column heading), stub (row heading), body, footnote, source. Bar diagrams: simple, multiple, subdivided, percentage; pie chart: angle = (value/total) x 360. Histogram: bars touching; frequency polygon: joining mid-points; ogive: cumulative frequency curve (less than and more than; intersection gives the median). Time series graph. Merits of diagrams: attractive, easy to understand; demerits: only approximate.
