@study
Memory is the process of encoding, storing and retrieving information. Encoding converts information into a form that can be stored; storage retains it; retrieval brings it back. The Atkinson-Shiffrin multi-store model (1968) describes three stores: the sensory memory (iconic for vision and echoic for hearing; holds information for a fraction of a second to two seconds), short-term memory (STM; limited capacity of about 7 plus or minus 2 items according to George Miller; lasts about 20 to 30 seconds without rehearsal) and long-term memory (LTM; unlimited capacity and long duration). Rehearsal moves information from STM to LTM; chunking increases STM capacity. Types of LTM: declarative or explicit memory (episodic memory of personal events and semantic memory of facts and concepts) and procedural or implicit memory (skills such as cycling). Levels of processing (Craik and Lockhart) argues that deeper, meaningful processing leads to better memory. Working memory (Baddeley and Hitch) has a central executive, phonological loop and visuospatial sketchpad. Serial position effect: the primacy and recency effects. Forgetting: Hermann Ebbinghaus (1885) studied memory with nonsense syllables and drew the forgetting curve showing rapid loss in the first hours. Causes: decay (trace fades with time), interference (proactive: old learning interferes with new; retroactive: new learning interferes with old), retrieval failure (information is stored but cannot be accessed; tip-of-the-tongue phenomenon), motivated forgetting (repression, per Freud) and amnesia (due to brain injury: retrograde and anterograde). Eyewitness memory is reconstructive; Elizabeth Loftus showed that leading questions alter memory. Flashbulb memories are vivid memories of emotional events. Improving memory: mnemonics (acronyms, method of loci, imagery, rhymes, peg word), organisation, elaboration, spaced practice, adequate sleep and the PQRST method (Preview, Question, Read, Self-recitation, Test). Memory aids include cues and context (state-dependent and context-dependent memory). Recall, recognition and relearning are measures of retention; recognition is generally easier than recall; savings method by Ebbinghaus measures relearning. Distributed practice is better than massed practice. Memory declines with age and disease such as Alzheimer's disease. Reconstruction and schemas (Bartlett) shape remembering.
## Deep dive: Stages and stores
Information passes through sensory memory, STM and LTM. Attention selects information for STM. Rehearsal and meaning transfer it to LTM.
## Deep dive: Types of LTM
Explicit memory includes events and facts; implicit memory includes skills and habits. Procedural memory is hard to put into words.
## Deep dive: Forgetting and improvement
Decay, interference and retrieval failure cause forgetting. Mnemonics, spaced study and sleep improve memory.
