# Introduction to Problem Solving
minutes: 35
yt: class 11 computer science problem solving algorithm flowchart pseudocode
@study
Steps in problem solving: analysing the problem, developing an algorithm, coding, testing and debugging. Algorithm: finite step-by-step procedure; characteristics: precision, uniqueness, finiteness, input, output. Representation: flowchart (oval start/stop, parallelogram input/output, rectangle process, diamond decision, arrows) and pseudocode. Decomposition: breaking a problem into subproblems. Control structures: sequence, selection, iteration. Verifying algorithms by dry run. Comparison of algorithms by efficiency (time and space). Examples: largest of three numbers, sum of n numbers, factorial, prime test, Fibonacci, GCD, linear search. Types of errors: syntax, logical, runtime.
## Deep dive: Algorithm and flowchart
Algorithm to find the sum of two numbers: START, read A and B, SUM = A + B, print SUM, STOP. Flowchart symbols: terminal (oval), input/output (parallelogram), process (rectangle), decision (diamond), connector (circle), flow lines (arrows). Pseudocode uses keywords like INPUT, IF, THEN, ELSE, WHILE, FOR, PRINT. Dry run uses sample data and a trace table to check.
## Deep dive: Control structures and examples
Sequence: statements in order. Selection: IF-THEN-ELSE. Iteration: loops. Examples: Even or odd: if N mod 2 = 0. Largest of three: compare. Factorial: product of 1 to n. Prime: no divisor from 2 to sqrt(n). Fibonacci: next = previous two. GCD by Euclid. Linear search: compare each element until found. Decomposition simplifies complex tasks, for example building a calculator from add, subtract, multiply.
## Deep dive: Testing and debugging
Syntax errors violate language rules; runtime errors occur during execution (division by zero); logical errors give wrong output. Debugging: tracing, print statements, debuggers. Testing with boundary and typical cases. Documentation and maintenance. Efficiency: number of steps grows with input (linear, quadratic). Pseudocode versus flowchart.

A: Start; read N; F=1, I=1; while I<=N: F=F*I, I=I+1; print F; stop.
