# Emerging Trends
minutes: 35
yt: class 11 computer science emerging trends AI IoT cloud big data blockchain
@study
Emerging technologies: artificial intelligence (AI), machine learning (ML), natural language processing (NLP), immersive experience (augmented reality AR, virtual reality VR), robotics, big data (volume, velocity, variety, veracity, value), data analytics, internet of things (IoT), cloud computing (SaaS, PaaS, IaaS; public, private, hybrid), grid computing, blockchain, sensors and smart cities, smart homes, wearables, 3D printing, cyber security. Machine learning: supervised, unsupervised, reinforcement. Deep learning uses neural networks. Digital footprint. Applications: chatbots, recommendation systems, self-driving cars, voice assistants. Issues: privacy, bias, job loss, ethics.
## Deep dive: AI, ML and NLP
AI is the ability of machines to mimic intelligent behaviour. ML learns from data; types: supervised (labelled data), unsupervised (clustering), reinforcement (rewards). NLP lets computers understand human language (translation, speech recognition, sentiment analysis). Computer vision, expert systems, chatbots, deep learning with neural networks. Turing test. Ethical concerns: bias, transparency, accountability, deepfakes.
## Deep dive: IoT, cloud and big data
IoT connects physical objects with sensors and networks (smart home, smart agriculture, wearables). Cloud computing delivers services over the Internet: IaaS (infrastructure), PaaS (platform), SaaS (software); benefits: scalability, cost saving, accessibility. Big data: 5 Vs; tools Hadoop, Spark. Blockchain: distributed ledger of linked blocks with hash, tamper resistance, used in cryptocurrency (Bitcoin), supply chain. Edge and grid computing.
## Deep dive: AR, VR, robotics and society
AR overlays digital information on the real world (Pokemon Go); VR creates a fully simulated environment. Robotics: machines performing tasks automatically (industrial robots, drones). 3D printing builds objects layer by layer. Cyber security threats: malware, phishing, ransomware. Issues: digital divide, e-waste, privacy, data protection laws.
