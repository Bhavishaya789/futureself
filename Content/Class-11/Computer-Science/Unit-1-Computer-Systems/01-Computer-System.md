# Computer System
minutes: 40
yt: class 11 computer science computer system CPU memory software
@study
A computer system has hardware and software. Input unit, CPU (ALU, CU, registers), output unit, memory. Von Neumann architecture: stored program. Memory hierarchy: registers, cache, RAM (primary, volatile), ROM, secondary storage (HDD, SSD, optical, USB flash). Units: bit, nibble, byte, KB (1024 B), MB, GB, TB. Interface and ports: USB, HDMI, VGA, Ethernet. Software: system software (operating system, language processors, device drivers, utilities), application software (general purpose, customised, utility). Language processors: assembler, compiler, interpreter. Operating system functions: process management, memory management, file management, device management, user interface. Boolean logic: AND, OR, NOT, NAND, NOR, XOR; truth tables; De Morgan laws; logic gates.
## Deep dive: Hardware organisation
Microprocessor with clock speed in GHz; instruction cycle fetch-decode-execute; registers hold data temporarily; ALU does arithmetic and logic; CU controls. Primary memory: RAM is volatile and holds running programs; ROM is non-volatile (BIOS). Cache is fast memory between CPU and RAM. Secondary: magnetic (HDD), optical (CD, DVD, Blu-ray), flash (SSD, pen drive, SD card). Input devices: keyboard, mouse, scanner, microphone, touch screen, sensors. Output devices: monitor, printer (impact and non-impact), plotter, speakers, projector.
## Deep dive: Software and OS
System software manages hardware; compilers translate the whole program to machine code and report errors together; interpreters translate and execute line by line; assemblers convert assembly to machine code. Operating system provides interface (CLI, GUI), schedules processes, manages memory, files and devices. Examples: Windows, Linux, macOS, Android. Utility software: antivirus, disk defragmenter, backup. Application software: word processors, spreadsheets, presentations, databases. Free and open source (FOSS), proprietary, freeware, shareware.
## Deep dive: Boolean logic
Logic gates: AND outputs 1 only if both inputs are 1; OR outputs 1 if either is 1; NOT inverts; NAND and NOR are universal gates; XOR outputs 1 when inputs differ. De Morgan: (A.B)' = A' + B'; (A+B)' = A'.B'. Truth table for n inputs has 2^n rows. Uses: circuits, search conditions, decision making. Boolean identities: A + 0 = A; A . 1 = A; A + A' = 1; A . A' = 0.
