# Applications of Computers in Accounting
minutes: 30
yt: class 11 accountancy computers in accounting spreadsheet database
@study
Computerised accounting uses software to record, store and report accounting information. Features: speed, accuracy, automation, security, reports and integration. Components: hardware, software, data, procedures, people. Types: accounting software ready-made (Tally, QuickBooks), customised, tailored and ERP. The process: create company, create ledgers, record vouchers, generate trial balance and final accounts. A spreadsheet helps to analyse data using formulas, functions (SUM, AVERAGE, IF, VLOOKUP), charts and pivot tables. A database stores records in tables with primary keys; queries retrieve data. Advantages: speed, accuracy, savings, reports, security. Limitations: cost, training, virus and data loss risk. Security through passwords, backup, firewall, encryption.
## Deep dive: Computerised accounting
Features: accuracy, speed, up-to-date reports, instant trial balance, voucher entry, GST integration, and secure access. Master data includes ledgers and stock items; transaction data includes vouchers. Steps: install and create company, set features, create account groups and ledgers, record vouchers (receipt, payment, contra, journal, sales, purchase), generate reports (trial balance, P and L, balance sheet).
## Deep dive: Spreadsheet and database
Spreadsheet: workbook, worksheet, cell address (A1), formula (=A1+B1), functions SUM, AVERAGE, MAX, MIN, IF, charts. Used for depreciation schedules, ratio analysis, payroll and budgets. Database: data stored in tables of fields and records; primary key identifies each record; DBMS software like MS Access, MySQL; SQL queries retrieve data.
## Deep dive: Security and controls
Threats: unauthorised access, virus, accidental deletion, hardware failure. Controls: user ID and password, access rights, regular backup, antivirus, firewall, encryption, audit trail. Cloud accounting gives remote access but needs internet security.
## Deep dive: Advantages and limits
Advantages: speed, accuracy, saving of space and effort, easy corrections, better reports, wide access. Limitations: initial cost, need for trained staff, risk of virus and data loss, dependence on electricity and hardware, security risk.
