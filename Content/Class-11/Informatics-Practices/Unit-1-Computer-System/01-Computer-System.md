# Computer System
minutes: 40
yt: class 11 informatics practices computer system hardware software memory
@study
A computer system is a combination of hardware and software that accepts data (input), processes it and produces results (output). The main hardware units are the input devices (keyboard, mouse, scanner), the Central Processing Unit or CPU with its Arithmetic Logic Unit (ALU), Control Unit (CU) and registers, the memory and the output devices (monitor, printer). Memory is of two types: primary memory (RAM, which is volatile, and ROM, which is non-volatile) and secondary memory (hard disk, SSD, pen drive, CD/DVD). Units: 1 byte = 8 bits, 1 KB = 1024 bytes, 1 MB = 1024 KB, 1 GB = 1024 MB, 1 TB = 1024 GB. Software is of three types: system software (operating system such as Windows, Linux, Android; language processors; device drivers), application software (word processor, spreadsheet) and utility software (antivirus, disk cleaner). Language processors translate a program: an assembler converts assembly language to machine language, a compiler translates the whole program at once, and an interpreter translates and runs it line by line. Python uses an interpreter. Computers store everything in binary; number systems include decimal (base 10), binary (base 2), octal (base 8) and hexadecimal (base 16). Encoding schemes include ASCII (7 bits, 128 characters), ISCII for Indian scripts and Unicode, which covers all languages. The operating system manages memory, processes, files and devices; examples of types are single-user, multi-user and real-time. A computer has a bus system to carry data and the ports connect devices such as USB and HDMI.
## Deep dive: Hardware
The CPU is the brain: ALU does arithmetic and logic, CU controls operations, registers hold data temporarily. Cache is a small fast memory between CPU and RAM. RAM holds running programs; ROM stores startup instructions. Secondary memory stores data permanently.
## Deep dive: Software and translators
System software runs the machine; application software helps users. A compiler checks the entire code and gives errors together; an interpreter stops at the first error. Open source software can be modified, as with Linux and Python.
## Deep dive: Number systems and encoding
Binary uses 0 and 1; octal uses 0-7; hexadecimal uses 0-9 and A-F. Conversions use repeated division or place values. ASCII gives each character a code, for example A is 65. Unicode (UTF-8) supports all scripts, including Devanagari.
