# Linear inequalities
minutes: 30
yt: class 11 linear inequalities
@study
An inequality compares two expressions with <, >, <= or >=. Adding or subtracting the same number keeps the sign; multiplying or dividing by a negative number reverses it. Solutions are written as intervals; two-variable inequalities represent half-planes bounded by a line.
## Deep dive: rules and intervals
Rules: (i) equal numbers can be added to or subtracted from both sides; (ii) both sides can be multiplied or divided by a positive number; (iii) multiplying or dividing by a negative number reverses the inequality sign. Solution sets are intervals: (a, b) open, [a, b] closed, [a, b) half-open; infinity is never included. For example x >= 2 is [2, infinity) and x < 5 is (-infinity, 5). Integer solutions: list the integers inside the interval. Natural number solutions begin at 1.
## Deep dive: compound and modulus inequalities
A compound inequality a < x < b means x > a and x < b together (intersection). For |x| < a (a > 0): -a < x < a. For |x| > a: x < -a or x > a. For |x - c| <= d: c - d <= x <= c + d. Always check the endpoints against the original strict or non-strict sign.
## Deep dive: graphical solution of two-variable inequalities
To graph ax + by <= c, draw the line ax + by = c (dashed for strict, solid for non-strict), test the origin (0, 0) and shade the side that satisfies the inequality; if the line passes through the origin test another point. The solution of a system is the common shaded region, which can be bounded or unbounded.
