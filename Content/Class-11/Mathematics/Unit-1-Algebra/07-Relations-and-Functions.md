# Relations and Functions

@study
The Cartesian product A x B is the set of all ordered pairs (a, b) with a in A and b in B; (a, b) = (c, d) only if a = c and b = d. A x B is not equal to B x A in general, and n(A x B) = n(A) n(B). A relation R from A to B is any subset of A x B. The domain is the set of first elements, the codomain is B and the range is the set of second elements actually used. The number of relations from A to B is 2^(mn) where m = n(A) and n = n(B). A function f from A to B assigns to each element of A exactly one element of B, written f: A -> B. Every function is a relation, but not every relation is a function. Domain is A, codomain is B and range is the set of images. Types of function: constant, identity f(x) = x, polynomial, rational, modulus f(x) = |x|, signum, greatest integer f(x) = [x], linear, quadratic. Real functions: the domain of 1/x is R - {0}; of sqrt(x) is x >= 0; of log x is x > 0. Graphs: f(x) = x^2 is a parabola, f(x) = |x| is a V shape, f(x) = [x] is a step graph, f(x) = 1/x is a hyperbola. Algebra of functions: (f + g)(x) = f(x) + g(x), (fg)(x) = f(x)g(x), (f/g)(x) = f(x)/g(x) with g(x) not 0 and (cf)(x) = c f(x). Counting: the number of functions from A to B is n^m; the number of one-one functions is nPm when n >= m. The vertical line test checks whether a graph is a function. The relation can be shown by an arrow diagram, a roster form or a table.
## Deep dive: Relations
A relation can be described by a rule such as y = x + 2. Domain and range are found from the pairs. The inverse relation swaps the elements of the pairs. A relation on A has subsets of A x A.
## Deep dive: Functions
For a function, each input has one output. In an arrow diagram no element of A is left without an arrow and none has two arrows. Range is a subset of codomain. Piecewise functions use different rules on different intervals.
## Deep dive: Domain and graphs
For sqrt(f(x)) need f(x) >= 0. For 1/f(x) need f(x) not 0. For log f(x) need f(x) > 0. Modulus function is non-negative. Greatest integer function [x] gives the largest integer not greater than x.
