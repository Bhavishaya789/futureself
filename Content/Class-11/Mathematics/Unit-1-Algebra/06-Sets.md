# Sets

@study
A set is a well-defined collection of distinct objects. Sets are written in roster form {1, 2, 3} or set-builder form {x : x is a natural number less than 4}. Standard sets: N (natural numbers), W (whole numbers), Z (integers), Q (rationals), R (reals). The empty set is written as {} and has no elements; a singleton has one element; a finite set has a countable number of elements. Two sets are equal if they have the same elements; equivalent sets have the same number of elements. A is a subset of B if every element of A is in B. The power set P(A) is the set of all subsets; if A has n elements, P(A) has 2^n elements and there are 2^n - 1 proper subsets. A proper subset is a subset that is not equal to the set. Intervals: open (a, b), closed [a, b], and half open [a, b) or (a, b]. Operations: union A U B (elements in A or B), intersection A n B (elements in both), difference A - B (in A but not B), complement A' = U - A and symmetric difference. Disjoint sets have empty intersection. Laws: commutative, associative, distributive A U (B n C) = (A U B) n (A U C), identity, idempotent, De Morgan (A U B)' = A' n B' and (A n B)' = A' U B'. Cardinality: n(A U B) = n(A) + n(B) - n(A n B), and for three sets n(A U B U C) = n(A) + n(B) + n(C) - n(A n B) - n(B n C) - n(A n C) + n(A n B n C). n(A') = n(U) - n(A). Venn diagrams use circles in a rectangle to show sets, introduced by John Venn. The number of elements in A x B is n(A) times n(B).
## Deep dive: Representation and types
Roster lists elements; set-builder gives a rule. Empty, singleton, finite, infinite, universal and equal sets are the main types. A set does not repeat elements. Notation: x in A means x belongs to A.
## Deep dive: Operations and laws
Union combines, intersection shares, difference removes. De Morgan laws connect complements. Distributive laws are used to simplify expressions. A - B equals A n B'.
## Deep dive: Counting with Venn diagrams
For word problems define sets, draw circles and fill the central region first. n(A U B) = n(A) + n(B) - n(A n B). The number who like exactly one of A or B is n(A) + n(B) - 2n(A n B).
