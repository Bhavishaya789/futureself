FutureSelf runs on Windows PCs and Android phones.

FutureSelf for Windows

Download SetupFutureSelf-Setup.exe
  1. Double-click FutureSelf-Setup.exe after it downloads.
  2. If Windows says "protected your PC" (the file is new and not code-signed yet): More info, then Run anyway.
  3. It installs for your account (no administrator needed), adds Start menu and desktop icons and opens by itself.
  4. To link your phone later: Settings, Link your Android phone, New code.

FutureSelf for Android

Download appFutureSelf.apk
  1. Tap the downloaded file. Android asks to allow Install unknown apps for your browser: allow it once.
  2. Open FutureSelf, go to Phone & lock and turn on the switches: App lock, Display over other apps, Calls, Notifications, Battery.
  3. Add up to five emergency numbers. They stay callable from the lock screen.
  4. Link your PC: PC app Settings, Phone link, New code. On the phone press Find my PC and type the code (same Wi-Fi).
